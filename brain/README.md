# ElmsNest Brain

قاعدة المعرفة التشغيلية لبزنس ElmsNest — تُفتح كـ **Obsidian vault** ويقرأ منها **Claude Code**.

## التشغيل على جهازك

```bash
git clone <repo-url>
cd ElmsNest/brain
```

ثم في Obsidian: **Open folder as vault** ← اختر مجلد `brain`.
هذا كل شيء. الملفات Markdown عادية — لا إضافات ولا إعدادات.

لتشغيل Claude Code عليه:

```bash
cd brain && claude
```

ملف `CLAUDE.md` سيُحمَّل تلقائياً، والمهارات في `.claude/skills/` تصبح متاحة.

## المهارات الجاهزة

| المهارة | الاستخدام |
|---|---|
| `brand-voice` | تطبيق أو مراجعة نبرة البراند على أي نص |
| `write-ad` | إعلان كامل بثلاث زوايا للاختبار |
| `reply-customer` | رد على رسالة عميل |
