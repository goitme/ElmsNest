# IMAGES — concept «field» (content pages, 2026-09-07)

Nine photographs, all from the licensed internet pools (`../../../pdp3/images/` and `../../../home2/images/`; records in the two `manifest.jsonl`). Nothing is edited: every crop is CSS `object-fit:cover` + `object-position` on the original file (the theme build resizes to ≤ 1800 px / ≤ 220 KB as `assets/ens-page-*.jpg`, same crops). No faces, no brand marks, no baked text in any crop; the small plant labels of the Kew frame are not used (that frame was dropped — its temple is a landmark at every usable aspect). Every CC BY / BY-SA frame carries a drawn credit («צילום: author (licence)», 12 px, `--env2-mute`) in the caption; CC0 / public-domain frames print «נחלת הכלל» instead. Every caption starts with a kicker that names what the picture is — **מקום** (a place) or **מנגנון** (a mechanism) — so no photograph can be read as the store's product; none of the nine contains a garden lamp of the kinds the store sells.

Crop notation: `390` = the phone plate (350 px wide inside the gutters), `1366` = the desktop plate (936 px content column, or 240 px margin column for the marginal figures).
