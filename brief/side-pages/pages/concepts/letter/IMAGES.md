## Theme assets (the deploy, not the concept)

Each used frame becomes `assets/ens-page-<page>-<word>.jpg` (guide-dusk, guide-panel, guide-night, about-grove, why-sunrise, why-cell, faq-terrace, proc-desert, contact-court), resized to ≤ 1800 px on the long side and pre-cropped to exactly the CSS window above (so the shipped file itself holds no figure and no post), ≤ 220 KB each (`prepare-assets.py`, resize + crop only, no retouching). An `image_picker` per slot overrides the asset; the `object-position` settings crop the owner's picture the same way. The CC BY / BY-SA credit text is a schema setting with the string above as default and is drawn whenever it is non-blank; the public-domain slot ships blank.
