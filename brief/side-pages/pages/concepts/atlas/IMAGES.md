## Theme assets (for the build, not done here)

Each file becomes `assets/ens-page-<page>-<n>.jpg`, ≤ 1800 px on the long side, ≤ 220 KB (the existing `prepare-assets.py` of the home round; the tiles at 900 px ≤ 90 KB each so the guide's four together stay under two full-width files). `image_picker` settings override each asset; `object_position` / `object_position_desktop` text settings carry the crops above; `credit` and `caption` text settings carry the lines above (empty = nothing drawn). The first photograph of a page is `loading="eager"`, the rest `loading="lazy"`; every `<img>` has `width`/`height`, `sizes="100vw"` for the bands and `sizes="(min-width:901px) 25vw, 50vw"` for the tiles.

## Not used, and why

- `wm_1cfe403a9a` (night path with three path lights, CC BY-SA 4.0) — the shortlist's «content: guide» pick, but path lights in a guide tile that links to the path-light collection would read as the store's product; the atlas needs places without fixtures.
- `wm_a17b65ac2a` (dusk garden path, CC BY-SA 3.0) — the row's second choice for שביל; the stone path at sunset is the more Mediterranean frame and carries a wall, so the same tile also says «garden wall».
- `ov_c3ee8ae1` (balcony at golden hour, CC BY-SA 2.0) — the only literal balcony, but a silhouetted tomato plant does not read as a place at 170 px; the terrace at dusk does.
- `wm_51200569f7` (sunrise through trees) — the sun as subject was considered for why-solar; the panel is the mechanism the copy names («הפאנל הסולארי נטען»), so it says more.
- Store frames (`../../pdp2/images/INVENTORY.md`, `home2/images/own/`) — no content page in this concept places a photograph beside copy about a store product; the guide's tiles name collections, not products, and the collection tiles on the home already use `collection.image`.
